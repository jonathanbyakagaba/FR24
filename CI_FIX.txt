Sixth instalment: run the night from the codespace, and the first-of-month bugs that came with it

Upload ci_fix.tar.gz (%d bytes, sha256 %s) and CI_FIX.txt at
https://github.com/jonathanbyakagaba/FR24/upload/main  ->  Commit directly to main

cd /workspaces/FR24
git pull
tar xzf ci_fix.tar.gz || tar xzf ci_install.tar.gz || tar xzf ci_instal.tar.gz
rm -f ci_fix.tar.gz ci_install.tar.gz ci_instal.tar.gz
chmod +x tools/nightly.sh
git add -A && git status --short
git commit -m "CI: tools/nightly.sh (fetch from the codespace); seed the cumulative tables into a new month; first-of-month crashes fixed; commit step names directories; fetch exit codes 3/4/5 separated"
git push

Then, in the same codespace terminal, run the night:

./tools/nightly.sh --dry-run     # four seconds: can this machine reach FR24, and what would it do
./tools/nightly.sh               # fetch, build, publish flight_paths/, snapshot weather, commit, push

Then Actions runs off your push and does nothing to the tables (no capture in the runner, on purpose).

Tested end to end here, on a fresh checkout of main with a real capture of 44 trails:
  ran 17, failed 0, warned 1, skipped 0 - 14 published file(s) touched, EXIT=0
The one warning is the honest one: the human screenshots are 35 days behind, copied forward by design.
